# רוחות · משחק פנס

**לשחק:** https://dtubugk-gif.github.io/flashlight-ghosts/

רוחות מרחפות בחדר שלכם, בתמונה של המצלמה. כוונו את הטלפון לכל פינה, והחזיקו אצבע על המסך כדי להדליק
את הפנס ולשרוף אותן לפני שהן מגיעות אליכם. אפשר לברוח, אבל הן ירדפו אחריכם עד שתשרפו אותן.

- הכי טוב בטלפון: המשחק משתמש במצלמה ובחיישני התנועה. בלי מצלמה בוחרים "בית רדוף".
- במחשב: גוררים עם העכבר כדי להסתכל, מחזיקים את הלחצן כדי להאיר, החצים מסובבים, WASD הולכים.
- חמש רוחות: רוח הסדין, הרוחונת המהירה, הג׳נטלמן שמתחמק מהאור, השדון שמתגנב מאחור, ורוח הרפאים הגדולה.
